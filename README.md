# 🧠 Neurone Artificiel from Scratch

Implémentation d'un neurone artificiel avec NumPy.
Basé sur le cours Machine Learnia (vidéo #05).

## Objectif
Programmer un perceptron capable de classification binaire.

## Stack
- Python 3.x
- NumPy
- Matplotlib
- Scikit-learn (pour le dataset)

## Installation locale
1. Installer Python 3.x.
2. Depuis le répertoire du projet :
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
3. Ouvrir `notebooks/01_neurone_artificiel.ipynb` avec Jupyter ou VS Code.
